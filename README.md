# Job Role Classifier

## Overview
NLP-based machine learning app that classifies resumes into 24 job categories.

## Live Demo
 https://job-role-classifier-1-wi9e.onrender.com

## Tech Stack
- Python, Pandas, NLTK
- Scikit-learn (TF-IDF, Random Forest)
- Flask, HTML, CSS

## What I Did
- Cleaned 2400+ resumes using NLTK
- TF-IDF vectorization with 7000 features and bigrams
- Compared 3 models — Random Forest achieved 76.1% accuracy across 24 categories
- Deployed as Flask web app

## How to Run
pip install -r requirements.txt
python app.py

## Dataset
Resume Dataset from Kaggle — 2400+ resumes across 24 job categories
